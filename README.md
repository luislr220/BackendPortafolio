# Portfolio Backend - .NET Practice

### **Infraestructura y Lógica de Servicios en C#**
Este proyecto constituye el núcleo lógico de mi portafolio personal. El objetivo principal es profundizar en el ecosistema de **.NET** y **C#**, aplicando patrones de diseño para el manejo de servicios externos y seguridad de identidad.

---

## Objetivos de Aprendizaje
* **Práctica de C#:** Implementación de lógica de negocio y controladores utilizando el framework .NET.
* **Integración de APIs de Terceros:** Gestión de servicios externos para almacenamiento y comunicación.
* **Seguridad Avanzada:** Desarrollo de flujos de autenticación robustos, incluyendo 2FA.

---

## Implementaciones Actuales
* **Gestión de Multimedia (Cloudinary):** Integración con la API de Cloudinary para el manejo, carga y optimización de imágenes del portafolio.
* **Sistema de Correspondencia (Brevo):** Implementación de la API de Brevo (Sendinblue) para el envío de correos transaccionales y códigos de verificación para el sistema de **2FA**.
* **Arquitectura de API:** Estructuración de endpoints siguiendo principios REST para una futura integración con el frontend (Angular/React).

---

## Estado del Proyecto
Actualmente, el proyecto se encuentra en **fase de desarrollo de backend**. El enfoque está en pulir la lógica de los servicios y la persistencia de datos antes de comenzar con la etapa de desarrollo de la interfaz de usuario.

---

## Requisitos
* .NET SDK (8)
* Cuenta y API Keys de Cloudinary y Brevo.
